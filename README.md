# Java Programming Lab

## About
This repository contains Java programs developed as part of Java programming lab practice.

## Programs

### 1. Student Details Using N Objects
- Creates a Student class.
- Stores USN, Name, Branch and Phone.
- Creates N student objects and displays their details.

### 2. Demonstrate Polymorphism Using Shape
- Creates a parent class Shape.
- Creates Circle, Triangle and Square subclasses.
- Demonstrates inheritance, method overriding and runtime polymorphism.

### 3. Resizable Interface Using Rectangle
- Creates a Resizable interface.
- Implements resizeWidth() and resizeHeight() methods.
- Demonstrates interface implementation using the Rectangle class.

## Technologies Used
- Java
- VS Code / GitHub Codespaces

## How to Run
Compile the Java program:

```bash
javac Main.java
```

Execute the program:

```bash
java Main
```
